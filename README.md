# Анастасия Шубина — недвижимость Москвы и области

Адаптивный сайт с восемью статическими страницами, блогом, руководством покупателя и двумя разделами рейтингов. Анимация появления блоков, мягкий параллакс фотографии, прогресс чтения, фильтры ЖК и мобильное меню. Без внешних JavaScript-зависимостей. Учитывает prefers-reduced-motion; контент доступен без JavaScript.

## Состояние

Проект: https://github.com/nickbelsov/anastasia-shubina. Публикация выполняется workflow GitHub Pages; статус запуска следует проверять в Actions.

## Редактирование

- `content/articles.json`: статьи. Для новой статьи добавьте объект с уникальным slug, title, category, description и sections (пары заголовок/текст).
- `content/ratings.json`: застройщики и ЖК. При обновлении также измените дату, методику и источник в `build.py`.
- `build.py`: страницы, метаданные, контакты, SEO, sitemap.
- `assets/style.css`: оформление и адаптивность.
- `assets/app.js`: взаимодействия и анимация.

Проверка локально:

```sh
python build.py
python -m http.server 8000
```

Для нового домена установите `SITE_URL` при сборке. После публикации проверьте canonical, sitemap, robots, подключите Яндекс Вебмастер и Google Search Console. Никакие счётчики или личные данные автоматически не собираются.

## GitHub Pages

Отдельный публичный репозиторий: `anastasia-shubina`. Загрузить все файлы в ветку main. Workflow `.github/workflows/pages.yml` собирает и публикует сайт. Если configure-pages не сможет включить Pages автоматически, выбрать Settings → Pages → Source: GitHub Actions. После успешного workflow ожидаемый адрес: https://nickbelsov.github.io/anastasia-shubina/ (не считать его рабочим до проверки).
